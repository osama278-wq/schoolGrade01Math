# رياضياتي – الصف الأول الأساسي (المنهج العماني) 🇴🇲

تطبيق ويب تعليمي تفاعلي (PWA) يعمل دون اتصال، لمادة **الرياضيات – الصف الأول الأساسي – الفصل الدراسي الأول** وفق **المنهج العماني (سلاسل كامبريدج)** و**وثيقة تقويم تعلم التلاميذ في مواد المجال الثاني (2026م)**.

يغطي التطبيق **جميع محطات كتاب التلميذ (ص ٤–٤٥)** في رحلة مغامرة عمانية، ويخدم ثلاث فئات: **التلميذ** و**المعلمة** و**ولي الأمر**.

## 📋 المطابقة مع وثيقة التقويم (2026م) – الصفان (١–٢)

| أداة التقويم | الدرجة | المعرفة والفهم | حل المشكلات | التوزيع في التطبيق |
|---|---|---|---|---|
| الحوار الشفوي | ٢٥ | ٢٠ | ٥ | ٣ رصدات حساب ذهني × ٣ + حوار (٥) + حوار (٦) + حوار حل مشكلات (٥) |
| العرض الشفوي | ٥ | ٥ | – | مرة واحدة وفق ٥ معايير أداء |
| الواجبات المنزلية | ٢٥ | ٢٠ | ٥ | ٤ × ٥ + ١ × ٥ (تُستورد آلياً من الواجبات الإلكترونية) |
| الأسئلة القصيرة | ٣٠ | ٢٠ | ١٠ | ٤ × ٥ + ٢ × ٥ (تُستورد آلياً من تذاكر الخروج) |
| المشروع | ١٥ | ٥ | ١٠ | التخطيط (٥) + التنفيذ (٥) في حل المشكلات، والتقرير (٥) في المعرفة |
| **المجموع** | **١٠٠** | **٧٠** | **٣٠** | لا توجد اختبارات قصيرة للصف الأول |

**قواعد إلزامية مطبّقة برمجياً** (`src/data/assessment.js`):
- منع أنصاف الدرجات (أعداد صحيحة فقط).
- منع منح درجة صفر عند تنفيذ الأداة (الحد الأدنى ١)؛ الخانة الفارغة = لم تُنفّذ بعد.
- منع تجاوز الدرجة العظمى لكل بند.
- تذكرة الخروج: ٣–٤ مفردات بترتيب تصاعدي للصعوبة، ١٠ دقائق كحد أقصى، درجة المفردة (٠، ١، ٢).
- الدرجات المستوردة آلياً لا تُستبدل إذا عدّلتها المعلمة يدوياً.

## 🛠️ المكدس التقني

- **React 18 + Vite 6 + React Router 6** (HashRouter ليعمل على GitHub Pages ودون اتصال)
- **Tailwind CSS 4** مع دعم كامل لـ RTL (`dir="rtl"` و`lang="ar"`) وخط Cairo
- **vite-plugin-pwa**: Service Worker + Manifest عربي + تخزين مؤقت للخطوط
- **IndexedDB** عبر مكتبة `idb` مع احتياطي `localStorage` وطابور مزامنة جاهز للربط بخادم
- **Web Speech API** (ar-OM ← ar-SA) للتوجيه الصوتي، و**Web Audio API** لمؤثرات مولّدة برمجياً (لا ملفات صوتية خارجية)
- **Pointer Events** للسحب والإفلات باللمس والفأرة والقلم (مناسب للسبورات الذكية)
- أزرار لمسية لا تقل عن ٤٨×٤٨ بكسل، وأرقام عربية مشرقية كما في كتاب التلميذ

## 🚀 التشغيل المحلي

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install
npm run dev        # خادم التطوير: http://localhost:5173
npm run build      # بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج (لاختبار العمل دون اتصال)
```

> ملاحظة: ميزة العمل دون اتصال (Service Worker) تعمل في نسخة الإنتاج (`build` ثم `preview`)، وليس في وضع التطوير.

### النشر على GitHub Pages
1. ارفع المشروع إلى مستودع على GitHub (الفرع `main`).
2. من **Settings → Pages → Source** اختر **GitHub Actions**.
3. يتولى الملف `.github/workflows/deploy.yml` البناء والنشر تلقائياً عند كل دفع.

## ⚙️ التخصيص

- **أسماء الشعبة:** من لوحة التحكم ← «تعديل أسماء الشعبة»، أو من `src/data/classroom.json`.
- **البيانات التجريبية:** لوحة التحكم ← «بدء فعلي (مسح الكل)» لبدء الرصد الحقيقي.
- **مستويات التحصيل (أ–هـ):** `LEVELS` في `src/data/assessment.js` (قابلة للتعديل وفق تعميم المديرية). يظهر «≈» قبل المستوى كمؤشر مبدئي حتى يكتمل الرصد.
- **ربط تذاكر الخروج بخانات السجل:** الحقل `exitTicket.slot` لكل محطة في `curriculum.json`.
- **الأسعار في محطة مطعم المدرسة:** أسعار تعليمية افتراضية بالريال لتبسيط الحساب.
- **المزامنة مع خادم:** مرّر دالة إرسال إلى `flushSync(sender)` في `src/utils/storage.js`.

## 🔒 الخصوصية

جميع البيانات (التقدم، الدرجات، الصور، التسجيلات) تُحفظ **محلياً على الجهاز** في IndexedDB، ولا تُرسل إلى أي خادم. استخدم «تصدير نسخة احتياطية» لنقل البيانات بين الأجهزة.

## 🌐 العربية ⇄ English (Language toggle)

زر عائم **«🌐 English / العربية»** في أسفل كل صفحة يبدّل لغة الواجهة كاملة (النصوص، اتجاه الصفحة RTL/LTR، الأرقام، النطق الصوتي)، ويُحفظ الاختيار على الجهاز.

A floating **🌐 English / العربية** button on every page switches the whole interface: text, page direction (RTL/LTR), digits (٠-٩ ⇄ 0-9), number words, and speech voice (Arabic ⇄ English). The choice is saved on the device.

| File | Role |
|---|---|
| `src/i18n/en.json` | Dictionary: `plain` (exact Arabic → English) and `tpl` (patterns with `{0}` placeholders) |
| `src/i18n/index.js` | Runtime: translates rendered text + `placeholder`/`title`/`aria-label`/`alt`, sets `dir`/`lang`, exposes `t()` |
| `src/i18n/LangToggle.jsx` | The toggle button and the root wrapper that re-renders the app on switch |

**Adding or fixing a translation:** edit `src/i18n/en.json`. In English mode, run `i18nMisses()` in the browser console to list any Arabic strings that still have no translation. Add `data-i18n-skip` to an element to keep it untranslated.
